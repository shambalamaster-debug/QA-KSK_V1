▼

มิติกระบวนการประเมินด้วย 4 ข้อบ่งชี้ A, D, L, I — ให้คะแนน 0–5 แต่ละข้อ

คะแนนระดับแนวทางการพิจารณา
0No Evidenceไม่มีการดำเนินการ A, D, L, I ตามข้อกำหนดของมาตรฐาน / ไม่มีหลักฐาน
1Beginningมีการดำเนินการ A, D, L, I เป็นส่วนน้อย (น้อยกว่าครึ่งหนึ่ง)
2Basically Effectivenessมีการดำเนินการ A, D, L, I เป็นส่วนใหญ่ (มากกว่าครึ่งหนึ่ง)
3Matureมีการดำเนินการ A, D, L, I ตามข้อกำหนดของมาตรฐานอย่างครบถ้วน
4Advanceมีการดำเนินการ A, D, L, I อย่างเป็นระบบ เพิ่มมากกว่าข้อกำหนดของมาตรฐาน
5Role Modelมีการดำเนินการ A, D, L, I เหนือมาตรฐาน เป็นแนวทางที่พิสูจน์ได้ว่านำสู่ความเป็นเลิศ

A=Approach  |  D=Deployment  |  L=Learning  |  I=Integration

มิติผลลัพธ์ประเมินด้วย 4 ข้อบ่งชี้ Le, T, C, I — ให้คะแนน 0–5 ตามร้อยละของตัวชี้วัดที่ดี

คะแนนระดับร้อยละตัวชี้วัดที่แสดง Le, T, C, I ที่ดี
0No Evidenceไม่มีรายงานข้อมูล/ตัวชี้วัดที่ดี
1Beginningร้อยละ 1–20
2Basically Effectivenessร้อยละ 21–40
3Matureร้อยละ 41–60
4Advanceร้อยละ 61–80
5Role Modelร้อยละ 81–100

Le=Level  |  T=Trend  |  C=Comparison  |  I=Integration

🔵 มิติกระบวนการ — คะแนนรายข้อ = min( (A+D+L+I) ÷ 4 , A )

  • หาก A = 0 → คะแนนข้อนั้น = 0 ทันที (ไม่ต้องพิจารณา D, L, I)
  • คะแนนรายข้อ ไม่เกิน ค่า A ที่ให้ไว้ (A เป็นเพดาน)
  • 14 ข้อ × 5 คะแนน = 70 คะแนน

🟢 มิติผลลัพธ์ — คะแนนรายข้อ = min( (Le+T+C+I) ÷ 4 , Le )

  • หาก Le = 0 → คะแนนข้อนั้น = 0 ทันที
  • คะแนนรายข้อ ไม่เกิน ค่า Le ที่ให้ไว้ (Le เป็นเพดาน)
  • 6 ข้อ × 5 คะแนน = 30 คะแนน

📊 คะแนนรวม = 70 + 30 = 100 คะแนน  |  ร้อยละ = คะแนนรวม

ร้อยละระดับลักษณะองค์กรพยาบาล
0–30Beginningเริ่มต้น กระบวนการยังไม่เป็นระบบ มีช่องว่างพัฒนาอีกมาก
30.01–40Basically Effectivenessแสดงประสิทธิผล ตอบสนองข้อกำหนดสำคัญบางส่วน
40.01–50Mature (ระดับ 1)ตอบสนองข้อกำหนดมาตรฐานเป็นส่วนใหญ่
50.01–60Mature (ระดับ 2)ตอบสนองข้อกำหนดมาตรฐานอย่างครบถ้วน เป็นระบบ
60.01–70Advanced (ระดับ 1)ตอบสนองมาตรฐานครบถ้วน มีการเรียนรู้และนวัตกรรม
70.01–80Advanced (ระดับ 2)ปฏิบัติตามมาตรฐานเป็นเลิศ มีนวัตกรรม บูรณาการ
80.01–90Role Model (ระดับ 1)แสดงการดำเนินการเหนือมาตรฐาน เป็นต้นแบบ
90.01–100Role Model (ระดับ 2)เหนือมาตรฐานอย่างโดดเด่น เป็นเลิศระดับชาติ

🗄️ นโยบายการจัดเก็บข้อมูลการประเมิน — ข้อมูลเก็บที่ไหน? ใครเข้าถึงได้? แก้ไขได้หรือไม่?

▼
📍 เก็บข้อมูลที่ไหน?
  • localStorage ของเบราว์เซอร์
    บนเครื่องคอมพิวเตอร์/แท็บเล็ต
    ของผู้ใช้งานโดยตรง
  • ไม่มีเซิร์ฟเวอร์ ไม่มีฐานข้อมูลกลาง
  • ข้อมูลอยู่ใน เบราว์เซอร์นั้น ๆ เท่านั้น
⏳ เก็บได้นานแค่ไหน?
  • เก็บถาวรจนกว่าจะลบ ไม่มีหมดอายุ
  • ปิด-เปิดเบราว์เซอร์: ข้อมูลยังอยู่
  • Autosave ทุกครั้งที่ตอบข้อ
  • ⚠️ ล้าง Cache/Cookies → ข้อมูลหาย
    ควร Export JSON สำรองทุกครั้ง
👤 ใครเข้าถึงได้บ้าง?
  • เฉพาะผู้ใช้เครื่องนั้น เท่านั้น
  • เฉพาะเบราว์เซอร์นั้น (Chrome ≠ Firefox)
  • ผู้ใช้คนอื่นเครื่องอื่น: เข้าไม่ได้
  • Admin/IT ไม่สามารถดูผ่านเครือข่ายได้
  • ข้อมูลไม่ถูกส่งออกไปยังอินเทอร์เน็ต
✏️ แก้ไขข้อมูลได้หรือไม่?
  • โหลดกลับมา → แก้ไขได้ → บันทึกใหม่
  • ดูผลเก่า (View): แก้ไขไม่ได้ read-only
  • ไฟล์ JSON ที่ Export: แก้ด้วย text editor แล้ว Import ใหม่ได้
  • ลบรายการ: ไม่สามารถกู้คืนได้
💾 พื้นที่จัดเก็บที่ใช้งานอยู่ คำนวณ...
— KB ใช้งาน ความจุสูงสุด ~5 MB
📋 คำแนะนำการใช้งานข้อมูลอย่างปลอดภัย
✅ Export JSON หลังบันทึกทุกครั้ง เก็บไว้ใน Google Drive / OneDrive
✅ ใช้ เบราว์เซอร์เดิมเครื่องเดิม เพื่อความต่อเนื่องของข้อมูล
✅ ตั้ง ชื่อรายการชัดเจน เช่น "ประเมิน Q1/2568 OPD"
✅ ก่อน Clear Cache ให้ Export ข้อมูลออกก่อน เสมอ
⚠️ อย่าใช้ Incognito/Private Mode ข้อมูลหายเมื่อปิด
⚠️ ผู้ที่ใช้เครื่องร่วมกัน อาจเห็นข้อมูลกันได้ ควรระวัง
ประเภทการจัดเก็บ: 🔒 localStorage (เฉพาะเครื่อง) 📤 JSON Export (ไฟล์สำรอง) ☁️ Cloud Storage (อนาคต)

🗄️ นโยบายการจัดเก็บข้อมูลการประเมิน — ข้อมูลเก็บที่ไหน? ใครเข้าถึงได้? แก้ไขได้หรือไม่?

▼
📍 เก็บข้อมูลที่ไหน?
  • localStorage ของเบราว์เซอร์บนเครื่องผู้ใช้งานโดยตรง
  • ไม่มีเซิร์ฟเวอร์ ไม่มีฐานข้อมูลกลาง
  • ข้อมูลอยู่ใน เบราว์เซอร์นั้น ๆ เท่านั้น
⏳ เก็บได้นานแค่ไหน?
  • เก็บถาวร จนกว่าจะลบเอง
  • ปิด-เปิดเบราว์เซอร์: ข้อมูลยังอยู่
  • ⚠️ ล้าง Cache → ข้อมูลหาย
    ควร Export JSON สำรองทุกครั้ง
👤 ใครเข้าถึงได้?
  • เฉพาะผู้ใช้เครื่องนั้น เท่านั้น
  • ผู้ใช้คนอื่นเครื่องอื่น: เข้าไม่ได้
  • ข้อมูลไม่ถูกส่งออกไปอินเทอร์เน็ต
✏️ แก้ไขข้อมูลได้หรือไม่?
  • โหลดกลับมา → แก้ไขได้ → บันทึกใหม่
  • ดูผลเก่า (View): read-only
  • ลบรายการ: ไม่สามารถกู้คืนได้
📋 คำแนะนำ: Export JSON ทุกครั้งหลังบันทึก  ·  ห้ามใช้ Incognito Mode  ·  ใช้เบราว์เซอร์เดิมเครื่องเดิมเพื่อความต่อเนื่อง
🔒 localStorage (เฉพาะเครื่อง) 📤 JSON Export (ไฟล์สำรอง)
📋 ข้อมูลการประเมิน — มาตรฐานและการประเมินคุณภาพการบริการพยาบาลผู้ป่วยอุบัติเหตุและฉุกเฉิน

📖 คำอธิบายวิธีการให้คะแนนและเกณฑ์การประเมิน (คลิกเพื่อแสดง/ซ่อน)

▼

มิติกระบวนการประเมินด้วย 4 ข้อบ่งชี้ A, D, L, I — ให้คะแนน 0–5 แต่ละข้อ

คะแนนระดับแนวทางการพิจารณา
0No Evidenceไม่มีการดำเนินการ A, D, L, I ตามข้อกำหนดของมาตรฐาน / ไม่มีหลักฐาน
1Beginningมีการดำเนินการ A, D, L, I เป็นส่วนน้อย (น้อยกว่าครึ่งหนึ่ง)
2Basically Effectivenessมีการดำเนินการ A, D, L, I เป็นส่วนใหญ่ (มากกว่าครึ่งหนึ่ง)
3Matureมีการดำเนินการ A, D, L, I ตามข้อกำหนดของมาตรฐานอย่างครบถ้วน
4Advanceมีการดำเนินการ A, D, L, I อย่างเป็นระบบ เพิ่มมากกว่าข้อกำหนดของมาตรฐาน
5Role Modelมีการดำเนินการ A, D, L, I เหนือมาตรฐาน เป็นแนวทางที่พิสูจน์ได้ว่านำสู่ความเป็นเลิศ

A=Approach  |  D=Deployment  |  L=Learning  |  I=Integration

คะแนนระดับร้อยละตัวชี้วัดที่แสดง Le, T, C, I ที่ดี
0No Evidenceไม่มีรายงานข้อมูล/ตัวชี้วัดที่ดี
1Beginningร้อยละ 1–20
2Basically Effectivenessร้อยละ 21–40
3Matureร้อยละ 41–60
4Advanceร้อยละ 61–80
5Role Modelร้อยละ 81–100

Le=Level  |  T=Trend  |  C=Comparison  |  I=Integration

🚑 โครงสร้างคะแนน ER (เล่ม 3) รวม 160 คะแนน

  • ส่วนที่ 1 มิติกระบวนการบริหาร (14 ข้อ × 5) = 70 คะแนน
  • ส่วนที่ 2 มิติกระบวนการปฏิบัติ (12 ข้อ × 5) = 60 คะแนน
  • ส่วนที่ 3 มิติผลลัพธ์ (6 ข้อ × 5) = 30 คะแนน
  • คะแนนรายข้อ = min( (A+D+L+I)÷4 , A ) หรือ min( (Le+T+C+I)÷4 , Le )
  • ร้อยละ = (คะแนนรวม ÷ 160) × 100
ร้อยละระดับลักษณะหน่วยงานบริการพยาบาล
0–30Beginningเริ่มต้น กระบวนการยังไม่เป็นระบบ
30.01–40Basically Effectivenessแสดงประสิทธิผล ตอบสนองข้อกำหนดบางส่วน
40.01–50Mature (ระดับ 1)ตอบสนองข้อกำหนดมาตรฐานเป็นส่วนใหญ่
50.01–60Mature (ระดับ 2)ตอบสนองข้อกำหนดมาตรฐานอย่างครบถ้วน
60.01–70Advanced (ระดับ 1)ตอบสนองมาตรฐานครบถ้วน มีการเรียนรู้และนวัตกรรม
70.01–80Advanced (ระดับ 2)ปฏิบัติตามมาตรฐานเป็นเลิศ มีนวัตกรรม
80.01–90Role Model (ระดับ 1)แสดงการดำเนินการเหนือมาตรฐาน เป็นต้นแบบ
90.01–100Role Model (ระดับ 2)เหนือมาตรฐานอย่างโดดเด่น เป็นเลิศระดับชาติ
🚑 โครงสร้างคะแนน ER :   ส่วนที่ 1 มิติกระบวนการบริหาร (14 ข้อ × 5 = 70 คะแนน)  +  ส่วนที่ 2 มิติกระบวนการปฏิบัติ 3 ระยะ (12 ข้อ × 5 = 60 คะแนน)  +  ส่วนที่ 3 มิติผลลัพธ์ (6 ข้อ × 5 = 30 คะแนน)  =  รวม 160 คะแนน

⏳ รอรับข้อมูลจากหนังสือเล่ม 5
🛏️

มาตรฐานและการประเมินคุณภาพการบริการพยาบาลผู้ป่วยใน

แบบประเมินสำหรับหอผู้ป่วยในทุกประเภท ครอบคลุมกระบวนการพยาบาลองค์รวม การดูแลต่อเนื่อง
ความปลอดภัยของผู้ป่วย (Patient Safety Goals) และคุณภาพการบันทึกทางการพยาบาล

เล่ม 5มาตรฐานและการประเมินคุณภาพ
การบริการพยาบาลผู้ป่วยใน

📚 หนังสืออ้างอิง : มาตรฐานและการประเมินคุณภาพการบริการพยาบาลผู้ป่วยใน (เล่ม 5)

🏥 หน่วยงานที่ใช้ : งานการพยาบาลผู้ป่วยใน (IPD) / หอผู้ป่วยอายุรกรรม ศัลยกรรม โรงพยาบาลเขาสุกิม

📋 โครงสร้างการประเมิน : มิติกระบวนการ (ADLI) + มิติผลลัพธ์ (Le/T/C/I) = 100 คะแนน

📌 วิธีเพิ่มโมดูลนี้ : อัปโหลดหนังสือเล่ม 5 เพื่อให้นำข้อมูลแบบประเมินมาใส่ในโปรแกรม

⏳ รอรับข้อมูลจากหนังสือเล่ม 6
🦠

มาตรฐานและการประเมินคุณภาพการบริการพยาบาลป้องกันและควบคุมการติดเชื้อในโรงพยาบาล

แบบประเมินสำหรับงานป้องกันและควบคุมการติดเชื้อในโรงพยาบาล (IC) ครอบคลุมระบบ IC
การเฝ้าระวังการติดเชื้อ การจัดการความเสี่ยง และการปฏิบัติตามมาตรฐาน Standard Precaution

เล่ม 6มาตรฐานและการประเมินคุณภาพ
การบริการพยาบาลป้องกันและควบคุมการติดเชื้อฯ

📚 หนังสืออ้างอิง : มาตรฐานและการประเมินคุณภาพการบริการพยาบาลป้องกันและควบคุมการติดเชื้อในโรงพยาบาล (เล่ม 6)

🏥 หน่วยงานที่ใช้ : งาน IC / ทุกหน่วยงานการพยาบาล โรงพยาบาลเขาสุกิม

📋 โครงสร้างการประเมิน : มิติกระบวนการ (ADLI) + มิติผลลัพธ์ (Le/T/C/I) = 100 คะแนน

📌 วิธีเพิ่มโมดูลนี้ : อัปโหลดหนังสือเล่ม 6 เพื่อให้นำข้อมูลแบบประเมินมาใส่ในโปรแกรม

⏳ รอรับข้อมูลจากหนังสือเล่ม 7
🤰

มาตรฐานและการประเมินคุณภาพการบริการพยาบาลฝากครรภ์

แบบประเมินสำหรับงานฝากครรภ์ (ANC) ครอบคลุมการดูแลมารดาตั้งครรภ์ตลอดระยะฝากครรภ์
การเฝ้าระวังภาวะแทรกซ้อน การส่งเสริมสุขภาพ และการเตรียมความพร้อมก่อนคลอด

เล่ม 7มาตรฐานและการประเมินคุณภาพ
การบริการพยาบาลฝากครรภ์

📚 หนังสืออ้างอิง : มาตรฐานและการประเมินคุณภาพการบริการพยาบาลฝากครรภ์ (เล่ม 7)

🏥 หน่วยงานที่ใช้ : งานฝากครรภ์ / คลินิกฝากครรภ์ โรงพยาบาลเขาสุกิม

📋 โครงสร้างการประเมิน : มิติกระบวนการ (ADLI) + มิติผลลัพธ์ (Le/T/C/I) = 100 คะแนน

📌 วิธีเพิ่มโมดูลนี้ : อัปโหลดหนังสือเล่ม 7 เพื่อให้นำข้อมูลแบบประเมินมาใส่ในโปรแกรม

⏳ รอรับข้อมูลจากหนังสือเล่ม 8
💬

มาตรฐานและการประเมินคุณภาพการบริการพยาบาลด้านการปรึกษาสุขภาพ

แบบประเมินสำหรับงานให้การปรึกษาสุขภาพ ครอบคลุมทักษะการให้การปรึกษา ระบบการส่งต่อ
การให้ข้อมูลสุขภาพ และการส่งเสริมพฤติกรรมสุขภาพที่พึงประสงค์

เล่ม 8มาตรฐานและการประเมินคุณภาพ
การบริการพยาบาลด้านการปรึกษาสุขภาพ

📚 หนังสืออ้างอิง : มาตรฐานและการประเมินคุณภาพการบริการพยาบาลด้านการปรึกษาสุขภาพ (เล่ม 8)

🏥 หน่วยงานที่ใช้ : งานการปรึกษาสุขภาพ / คลินิก NCD คลินิกสุขภาพจิต โรงพยาบาลเขาสุกิม

📋 โครงสร้างการประเมิน : มิติกระบวนการ (ADLI) + มิติผลลัพธ์ (Le/T/C/I) = 100 คะแนน

📌 วิธีเพิ่มโมดูลนี้ : อัปโหลดหนังสือเล่ม 8 เพื่อให้นำข้อมูลแบบประเมินมาใส่ในโปรแกรม

⏳ รอรับข้อมูลจากหนังสือเล่ม 9
🌳

มาตรฐานและการประเมินคุณภาพการพยาบาลในชุมชน

แบบประเมินสำหรับงานพยาบาลในชุมชน ครอบคลุมการเยี่ยมบ้าน การดูแลผู้ป่วยในชุมชน
การส่งเสริมสุขภาพ ป้องกันโรค และการฟื้นฟูสมรรถภาพในชุมชน

เล่ม 9มาตรฐานและการประเมินคุณภาพ
การพยาบาลในชุมชน

📚 หนังสืออ้างอิง : มาตรฐานและการประเมินคุณภาพการพยาบาลในชุมชน (เล่ม 9)

🏥 หน่วยงานที่ใช้ : งานเวชปฏิบัติครอบครัว / PCU / งานส่งเสริมสุขภาพ โรงพยาบาลเขาสุกิม

📋 โครงสร้างการประเมิน : มิติกระบวนการ (ADLI) + มิติผลลัพธ์ (Le/T/C/I) = 100 คะแนน
